# Jobify Asset Specifications

This directory contains photographic and portrait assets for the Jobify landing page.
All images use modern web formats (WebP/PNG), explicit intrinsic aspect ratios to eliminate cumulative layout shift (CLS), and unified cool-green/atmospheric color grading.

## Asset Slot Manifest

### 1. `hero-landscape.webp`
- **Recommended Dimensions:** 2400 × 1400 px
- **Format:** WebP (quality 85)
- **Focal Point:** Center (50% 40%)
- **Prompt:** "Cinematic misty rolling green hills, soft atmospheric haze, layered ridges, lush grass in foreground, desaturated cool tones, daylight, no people, no text, gentle fade to white at top"
- **Usage:** Section 02 Hero background layer

### 2. `hero-portrait.png`
- **Recommended Dimensions:** 900 × 1100 px
- **Format:** PNG with 8-bit Alpha Channel (transparent background)
- **Focal Point:** Upper center (face profile)
- **Prompt:** "Black-and-white side-profile portrait of a woman with a short textured pixie cut, eyes closed, chin slightly raised, black jacket, studio lighting, high contrast, isolated cutout on transparent background, lower torso fading out"
- **Usage:** Section 02 Hero center cutout layer

### 3. `feature-automation-bg.webp`
